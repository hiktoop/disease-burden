# 全球与中国疾病负担排行

一个纯静态数据页，统计**全球、全中国、分省**三个层级的疾病患病人数与死亡人数排行，每条数字都标注来源、年份与可靠度。

线上访问：`https://<你的用户名>.github.io/<仓库名>/`

---

## 为什么这份数据值得单独做一页

同一个问题"哪种病最多人得"，会有两个完全不同的答案，取决于问的是**患病**还是**死亡**：

| | 按现患人数 | 按死亡人数 |
|---|---|---|
| 全球第 1 | 口腔疾病 37.3 亿 | 缺血性心脏病 950 万 |
| 全球第 2 | 头痛障碍 29.0 亿 | 卒中 680 万 |

患病榜前四名在死亡榜上一条都看不到，死亡榜前两名在患病榜上挤不进前十。把两者混在一张表里排序，是这类统计最常见的错误。本页因此拆成独立两榜。

```
    ├── china_prevalence.csv                # 中国 · 按患病人数排序（22 项，分三层）

    ├── province_diabetes_2023.csv          # 省域 · 糖尿病年龄标化患病率（31 省）
    ├── province_hypertension_2012_2015.csv # 省域 · 高血压加权患病率（14 组）
    ├── sources.csv                         # 来源清单（21 条，含可靠度分级）
    └── sources.json                        # 来源清单 JSON（含链接、结构化）
```

CSV 均为 UTF-8 with BOM，Excel 双击打开不乱码。`sources.json` 结构如下：

```json
{
  "records": [
    {
      "id": 1,
      "source": "GBD 2023（Global Burden of Disease Study 2023）",
      "publisher_and_date": "IHME / 2025-10-12",
      "data_used": "全球 375 种疾病负担、患病与死亡排序、DALY 前十",
      "reliability": 3,
      "url": "https://www.healthdata.org/..."
    }
  ]
}
```

`reliability`：`3` = 官方统计或大样本实测 · `2` = 权威研究建模估计 · `1` = 推算或二手转引。

## 数据基准与版本

| 数据源 | 最新可用版本 | 更新周期 |
|---|---|---|
| GBD（全球疾病负担） | GBD 2023，2025-10-12 发布 | 约 2 年 |
| WHO Global Health Estimates | GHE 2023，2026-10-02 发布 | 年度 |
| 中国心血管健康与疾病报告 | 2025 版，2026-06 发布 | 年度 |
| 国家癌症中心肿瘤统计 | 2022 年数据，2024 年发表 | 约 2 年 |
| 中国高血压调查 | 2012–2015 | **十余年一次** |
| 全国口腔健康流调 | 第四次（2015–2017） | **约 10 年** |
| 中国精神卫生调查 | 2019 | **十余年一次** |

流行病学数据有固定的时间滞后：监测采样 → 死因登记 → 建模 → 同行评审 → 发布，通常晚 2–3 年。整张表看起来"旧"，原因是新一轮调查尚未开展，不是检索不足。

## 引用时必须连同年份与口径

**中国各组数字来自不同年份，不能计算增速或做精确跨病种排序。** 例如：

- 高血压 2.45 亿（2012–2015 中国高血压调查，≥18 岁加权患病率 23.2%）
- 糖尿病 2.33 亿（2023，20 岁以上，年龄标化患病率 13.67%）
- 慢阻肺约 1 亿（2018，40 岁以上患病率 13.7%）

**心血管病的两个数都对，但不能混用**：国家心血管病中心口径 3.3 亿（含 2.45 亿高血压）；GBD 口径 1.338 亿（不含高血压，GBD 将其视为风险因素）。

**COPD 的中外数据打架源于诊断标准差异**：GBD 2023 给中国 5250 万，中国肺功能流调给近 1 亿。

## 已知局限

1. **部分中国数字为不同年份拼接**，跨病种比较只能看量级，不能看精确排序。
2. **口腔疾病、近视、幽门螺杆菌的中国数字含推算成分**（`reliability` 为 1–2），"≈10 亿"是按成人牙周问题检出率 90.9% 乘成年人口得到的量级估计，非直接调查结果。
3. **癌症现患人数未列入**：官方未直接发布现患存量，按五年生存率 43.2% 与年新发 482 万推算约为 2000 万量级，故不列为正式排序项。
4. **市级患病率数据不存在**。可用的替代口径只有死因监测（605 个监测县区）、国家卫生服务调查的两周患病率、地方疾控年报。任何声称有全国市级患病率的来源都值得怀疑。
5. **省域排行混有检出率差异**。凡需主动筛查才能确诊的病（糖尿病、慢性肾病、COPD、脂肪肝），其省际差异含医疗可及性成分，不能直接当流行病学事实读。典型例子：河北高血压 23.3%（偏低）而糖尿病 14.55%（偏高）。

## 重新生成 data/ 下的 CSV

CSV 由 `index.html` 中的表格反向解析生成，页面是唯一数据源，两边不会不同步。修改页面数据后重新运行解析脚本即可。
